# First prototype checklist

- [ ] Both teammates can build and run the program on their Macs.
- [ ] Initial state is At depot with 0% progress.
- [ ] Start moves the parcel along the route.
- [ ] Pause freezes the parcel and progress.
- [ ] Resume continues from the paused position.
- [ ] Arrival stops at the destination with Delivered and 100% progress.
- [ ] Reset returns to the depot and 0% progress.
- [ ] Reset also works during a journey.
- [ ] Record a short screencast of the working prototype.
- [ ] Each teammate completes their own journal with actual contributions and AI use.

Suggested screencast: introduce the simulation, start, pause, resume, show delivery, reset.

Describe temperature and impact monitoring as planned features until implemented.
